# CARDReader Updates

This public repository is used **only to distribute signed Android APK updates** for CARDReader.

- **No personal records or user databases are published here.** Purchases, sales, inventory, notes, and JSON backups stay on the user's device.
- No private source repository, API tokens, passwords, or signing keys belong in this repository.
- Releases will contain a compiled APK and version information only.
- The Android app checks GitHub's public release metadata to find updates. GitHub receives normal network connection metadata such as IP address, but no ledger records.
- Android requires the user's permission before installing any update.

**Security:** install only the release assets linked from this repository. APKs can be inspected and redistributed by third parties.
